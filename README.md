# ASCII Ray Tracer

View the live demo: [https://luisberrospi.github.io/fire-pages/](https://luisberrospi.github.io/fire-pages/)

## About

This is a visualization of an ASCII ray tracer that renders 3D scenes using typographic characters. The project combines sophisticated 3D rendering algorithms with retro ASCII aesthetics.

## Source Code

The full Python source code is available at: [https://github.com/luisberrospi/fire](https://github.com/luisberrospi/fire)

## Deploy

To deploy to GitHub Pages:

1. Create a new repository named `fire-pages` on GitHub
2. Push this code:
   ```bash
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/luisberrospi/fire-pages.git
   git branch -M main
   git push -u origin main
   ```
3. Enable GitHub Pages:
   - Go to Settings → Pages
   - Source: main branch
   - Folder: / (root)
   - Save

Your site will be live at: `https://luisberrospi.github.io/fire-pages/`
